# Weights: round 1 recogniser

PaddleOCR PP-OCRv6 medium recogniser, fine-tuned on typed public Vietnamese filings made
to look scanned, with every test-set file and company left out. These are the weights of
the fine-tuned reader in the candidate measured on set F.

- `round1-rec.tar.gz`, SHA-256 `010c5757be568a258d6657402a3acbbf6450f46dd978840e4f5a298e1e22fd5e`
